# 智能比较设计与实施计划

目标：所有已配置规则参与搜索，先探测规格、排除较低分辨率，预选最多三个不同网站，再通过共同画面的真实模型评分推荐第一名。此方案按用户本次确认执行。

## 流程与边界

1. 智能模式为默认模式，搜索全部已配置规则，仍由用户确认同番、同季及同集的条目。原快速、完整模型模式保留兼容。
2. 所有候选先解析媒体和探测分辨率；HLS 主清单先选择最高分辨率子清单，后续规格必须来自同一媒体档位。
3. 智能模式只保留像素面积最高的有效来源。较低档不再估算体积、取样或推理；行仍保留并注明筛除原因。
4. 最高档先看真实视频码率；没有时，以已知体积或少量分片响应头估算平均总码率，再回退已探测的容器码率。只有唯一音轨且码率已知时才扣除，并明确估算范围。大小按时长归一化，峰值带宽不当平均码率。
5. 同编码及相近帧率按码率优先粗排，不把高帧率直接当更好。不同编码或明显不同帧率采用分组轮转保留候选，避免 H.265 因体积小被机械淘汰。每个规则只取一条最佳线路，最多三个规则入选；未知指标不能伪造成零或模型分数。
6. 入选来源评估三个共同正文位置，至少两个网站、三个共同位置才能形成跨站模型排名。唯一最高档作为规格候选展示，不伪造跨站模型排名。
7. 模型来源失败时从同最高档的备用名单有限补位，最多额外尝试两个网站；不重新引入已按用户要求排除的低档。
8. 响应头探测仅读 HEAD/Range 响应头，清单有限读取，绝不下载整集。网络请求数量、响应大小、重定向次数和耗时均有上限；保留鉴权、取消及签名地址脱敏边界。
9. 规格预选只是启发式：最高档、前三名限制可能漏掉低档高质量或未入选的优秀来源。页面标明“入选来源的模型推荐”，不声称穷举或人工观感的绝对最优。
10. HDR 保留真实规格，当前未校准 HDR 色调映射，不进入 SDR 模型比较；最高档仅有 HDR 时说明限制，不降档生成冠军。
