# 本地画质助手设计与实施计划

本方案根据用户要求采用独立本地工具形态，替代原先的内嵌页面方案。用户已明确要求直接可用、只服务本机、不修改 Kazumi main。

## 目标与边界

- 工具目录为 `D:\git\Kazumi-image-quality`，与 `D:\git\Kazumi` 完全分离。
- 双击启动脚本，浏览器打开仅监听 `127.0.0.1` 的中文页面。
- 只读安装版 Kazumi 的 `plugins/v2/plugins.json`，允许切换文件；不写入 Kazumi 配置、仓库或安装文件。
- 搜索名称，按网站展示规则搜索结果；唯一精确名称匹配可预选，同名季数或多个结果让用户选择正确条目。
- 对选定条目的相同集数进行解析、取样、内容匹配及无参考评分，输出网站及线路排名。
- 首版为实验性画质估计，实际推理必须可运行，不使用随机数或码率公式伪装画质评分。模型不可用时说明原因。
- 本机使用独立 Python 环境、FFmpeg 和 MUSIQ 模型。CPU 可用；安装大小、耗时以实际验证为准，不承诺超小体积或即时完成。
- 不能在未修改 Kazumi 的情况下添加应用内部按钮，也不承诺私有播放跳转协议。结果提供打开源站播放页和复制链接。
- 原内嵌方案中的模型精度目标保留为后续正式验证目标；首版不宣称通过动画领域校准。显示“实验性估计”，采用共同内容匹配后评分并公开覆盖样本数，低差异只给倾向，不伪造置信概率。

## 架构与接口

Python 本地服务提供 REST API，静态 HTML/CSS/JS 提供操作界面。搜索与分析在后台线程执行，支持取消和实时轮询。Playwright 仅作为工具内部媒体地址解析引擎，优先使用已安装 Edge；与用户日常浏览器会话分离。

### 规则模块 `helper/rules.py`

- `load_rules(path: str) -> list[dict]`：读取并验证规则 JSON（列表、单规则、常见包装），不写入源文件。
- `discover_rule_files() -> list[str]`：只检查常见 Kazumi 用户目录和 MSIX 安装目录。
- `search(rule: dict, keyword: str, timeout: float = 20) -> list[dict]`：每项为 `{title, url}`。
- `chapters(rule: dict, source: str, timeout: float = 20) -> list[dict]`：每项为 `{name, episodes: [{name, url, number}]}`，无法识别的集号为 `None`。
- 支持 Kazumi XPath 及 API JSONPath、模板、nested/delimited 章节；不支持的配置明确报错。

### 分析模块 `helper/media.py`、`helper/quality.py`

- 页面解析继承规则 User-Agent/Referer，在独立 Edge 会话监听媒体请求，返回媒体地址和必要请求上下文。
- FFmpeg 在本地提取元数据和多时间点帧；每个子进程有超时及取消。
- 用低分辨率指纹匹配同内容；至少三个共同位置验证成功才输出可比评分。参考来源只用于时间轴，不能当作无损原片。
- MUSIQ 在本机对统一显示口径的帧推理。公开实验状态、模型名称、样本数量及匹配情况。失败不填零。
- 原始媒体地址含签名时不写日志，临时帧在完成/取消后清理。

### 服务 `app.py`、`helper/jobs.py`

- `GET /api/config` 返回 `{rules_path, discovered_paths, rules:[{id,name}], model_ready, busy}`。
- `POST /api/config {rules_path}` 保存本工具规则路径。
- `POST /api/search {keyword, rule_ids?}` 返回 `{job_id}`。
- `GET /api/jobs/{id}` 返回 `{id, kind, status, message, progress, results, errors, episode?}`。
- 搜索结果 `{id, rule_id, site, title, url, selected}`。
- `POST /api/analyze {search_job_id, candidate_ids, episode?: number}` 返回 `{job_id}`。
- 分析结果 `{site,title,road,episode,page_url,status,score?,resolution?,codec?,samples?,message}`。
- `POST /api/jobs/{id}/cancel` 取消任务。
- 所有写操作限制同源、本机 Host 与会话令牌，防止任意网站控制本地服务；没有局域网监听。

### 界面 `web/index.html`、`web/style.css`、`web/app.js`

轻量浅色工作台。冷灰背景、靛蓝操作色、墨色正文，中文系统字体，数据等宽。主区域直接提供番剧搜索；下方为来源候选和排名表，侧栏显示规则连接、评分环境和操作说明。样本胶片条表达画质检测，避免营销式首页。

- [x] 集成验收：运行单元测试、真实模型推理、浏览器操作及本地实际来源搜索；能否完成实际媒体排名如实记录。
