`.runtime/`、`.venv/`、`data/`、`.idea/` 均被 Git 忽略。原 `D:\git\Kazumi` 的 `git status --short` 为空。

## 仍然存在的边界

模型未经过动画领域人工校准；有限取样不能代表整集；极慢响应头不保证硬实时截止；首版明确拒绝向 FFmpeg 传递 Cookie/Authorization。需要交互、验证码或特殊解密的网站可能无法检测。
